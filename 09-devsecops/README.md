# DevSecOps for Enterprise Platforms

This section focuses on enterprise DevSecOps practices used in modern cloud-native infrastructure, CI/CD platforms and Kubernetes environments.

DevSecOps integrates security directly into:
- development workflows
- CI/CD pipelines
- infrastructure automation
- cloud platforms
- Kubernetes delivery
- software supply chains

Security is no longer a separate phase.

Modern enterprise engineering requires security to be integrated continuously across the entire delivery lifecycle.
