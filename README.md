# Enterprise DevSecOps Platform Engineering

Most DevOps roadmaps online stop at:
- Docker
- Jenkins
- basic Kubernetes
- small CI/CD demos

But real enterprise environments involve much more than that.

This repository is a curated roadmap focused on:
- Enterprise DevSecOps
- Platform Engineering
- Cloud Infrastructure
- Kubernetes Operations
- GitOps
- SRE
- AI-assisted Infrastructure Engineering
- Observability
- Governance & Compliance
- Production Troubleshooting

The goal is to collect practical and enterprise-relevant knowledge in one place instead of maintaining another “awesome links” repository.
